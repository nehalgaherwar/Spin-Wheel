# 🎡 Spin Wheel Game (Spin & Win)

A fun **Spin Wheel / Lucky Draw** web project made using **HTML, CSS, and JavaScript**.  
Click the **SPIN** button and win random prizes 🎉

---

## 📌 Features
✅ Colorful prize wheel  
✅ Smooth spinning animation  
✅ Random prize selection  
✅ Pointer indicator  
✅ Result display + popup alert  
✅ Easy to customize prizes & colors  

---

## 🛠️ Technologies Used
- **HTML5**
- **CSS3**
- **JavaScript (Canvas API)**
